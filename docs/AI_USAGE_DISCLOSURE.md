# AI Usage Disclosure

Carried over unchanged from the project's academic report
(`docs/reports/Group29_Assignment1_Report.pdf`), because a disclosure of this kind
belongs with the work it describes and should not disappear when the code is
repackaged.

---

## Statement from the report

> **AI usage disclosure:** Portions of the work were supported by the use of
> AI-based language models (ChatGPT and Google Gemini) strictly for non-creative
> tasks such as: (i) debugging assistance during the implementation of the
> `NavigationNode` startup sequence, and (ii) improving the clarity and formatting
> of text in the report. All system architecture decisions, algorithms, control
> logic, perception modules, and ROS 2 code were fully designed and implemented
> solely by the authors.

---

## What this means for this repository

- **Debugging assistance** was used on the `NavigationNode` startup sequence —
  the part of `navigation_node.py` that waits for the Nav2 lifecycle services,
  issues `STARTUP`, and polls `ros2 lifecycle get /bt_navigator`.
- **The algorithms are the authors' own.** The Kalman filter formulation, the
  corridor hysteresis logic, the Euclidean clustering and the table width filter
  are original work.
- **Nothing in this repository was generated by AI.** The preparation pass that
  produced this repository — packaging, documentation, the architecture diagrams,
  the dependency corrections — is described in `docs/CHANGES.md`. It changed no
  algorithm, no threshold and no gain.

Note on the README: the READMEs, architecture diagrams and this document were
written by the repository maintainer during preparation. The disclosures above are
preserved unchanged because they describe the *original* project, which is what
this repository presents.
